# furmosa_menu

匠寵 Furmosa 凍乾目錄站複製版（視覺與互動對齊 [furmosa.com](https://www.furmosa.com)）。

## 開發

```bash
npm install
npm run dev
```

開啟 [http://localhost:3000](http://localhost:3000)。

## 頁面

- `/` — 凍乾目錄首頁（編號清單、關於匠寵）
- `/challenge` — 嗷嗚計劃：青蛙誰在怕

## 技術

- Next.js App Router
- React 19
- Tailwind CSS 4（全域基底）+ 原始站點 CSS 還原
